# Code of Conduct

## Our Standards

Contributors are expected to help maintain a professional, respectful, and collaborative development environment.

Examples of expected behavior include:

* Being respectful and constructive.
* Focusing feedback on the work rather than individuals.
* Accepting reasonable technical disagreements.
* Providing useful and actionable feedback.
* Respecting different levels of experience.
* Keeping discussions relevant to the project.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or personal attacks.
* Discriminatory or hateful language.
* Threats or intimidation.
* Deliberate disruption of project discussions.
* Publishing private or sensitive information without permission.
* Deliberately introducing malicious code or credentials.

## Reporting Issues

If you experience or observe unacceptable behavior, report it privately to the project maintainers rather than escalating the issue publicly.

For security vulnerabilities, follow the reporting process described in `SECURITY.md`.

## Enforcement

Project maintainers may take appropriate action when this code of conduct is violated, including removing inappropriate content, restricting participation in project discussions, or taking other reasonable measures to protect the project community.

## Scope

This Code of Conduct applies to project repositories, discussions, pull requests, issues, and other project-related interactions.
