# Changelog

All notable changes to the AI Code Documentation Tool are documented here.

## [Unreleased]

### Added

* Core AI code-analysis and documentation-generation pipeline.
* Modular AI provider architecture.
* AST-based code analysis.
* Documentation quality and stale-documentation checks.
* Security scanning and sensitive-data redaction.
* Provider-specific secret detection.
* High-entropy secret detection.
* Configurable security patterns.
* Structured AI output validation.
* Retry and timeout handling for AI providers.
* Automated tests with pytest and coverage reporting.
* Ruff linting and formatting checks.
* mypy static type checking.
* GitHub Actions CI for Python 3.11, 3.12, and 3.13.
* Contributor and security documentation.

### Improved

* Security handling before AI processing.
* Error handling across the AI pipeline.
* Type coverage across Core AI modules.
* Test coverage and edge-case handling.
* Repository development workflow.

## Development Notes

This project is currently under active development.

Backend and frontend components may evolve independently from the Core AI pipeline.
